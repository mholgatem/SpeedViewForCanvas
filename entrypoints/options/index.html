Canvas sites

SpeedView only runs on the SpeedGrader pages of these sites. Your browser will ask you to approve access when you add one.

    If you don't see the SpeedView drawer in SpeedGrader, then you likely need to add your school's custom canvas URL.

    Behavior

    Language overrides

    Map a file extension to a highlighting language, one per line, e.g. pde = java.

    Waveform layouts

    GTKWave signal lists you saved in the waveform viewer, by assignment. They hold only signal names and display settings, and stay in this browser. Delete them when no longer needed.

    Privacy

    SpeedView never sends student data anywhere. Files are downloaded straight from your Canvas site, viewed in memory, and discarded when you close them. There are no analytics, no external servers, and no remotely loaded code. Only the settings on this page (including any waveform layouts you save) are stored.
